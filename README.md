# TVTidy

Model-by-model guides to what is safe to disable on an Android TV or Google TV, plus a desktop helper
that applies and restores a debloat list. The package lists are derived from the
[CleanYourTV](https://github.com/Gathin23/cleanyourtv) community lists under the MIT License. TVTidy is
an independent project and is not affiliated with that project.

The plan, build order and launch kit live in [`docs/gtm-kit.md`](docs/gtm-kit.md). Project rules for
Claude Code are in [`CLAUDE.md`](CLAUDE.md).

## Layout

| Directory | What it is |
|---|---|
| `data/upstream/` | Untouched copy of the upstream lists, with their LICENSE and our NOTICE. Never edited by hand |
| `data/normalized/` | `models.json`, `brands.json`, `packages.json` and `changelog.json`, generated by `scripts/sync_upstream.py` |
| `data/overrides/` | Hand-written package descriptions and risk ratings that win over upstream data |
| `scripts/` | Python data pipeline: upstream sync and per-page data, with pytest tests in `scripts/tests/` |
| `site/` | Next.js 15 app, built as a static export to `site/out/` and deployed to Cloudflare Pages |
| `helper/` | Python desktop helper (`tvtidy_helper/`) and its PyInstaller build files (`build/`) |
| `worker/` | Cloudflare Worker that receives payment webhooks and writes licenses to Supabase |
| `supabase/migrations/` | Database schema for users, licenses, watches and list changes |
| `.github/workflows/` | `deploy.yml` (site deploy), `sync.yml` (nightly upstream sync); the helper release workflow comes later |
| `docs/` | The GTM kit, the upstream survey and `decisions.md` |

## Commands

Requires Node 20 (see `.nvmrc`) and Python 3.12+.

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
cd site && npm ci
```

| Command | What it does |
|---|---|
| `make sync` | Sync upstream at `HEAD` (or `--commit <sha>`) into `data/upstream/` and `data/normalized/`; the clone is cached in `~/.cache/tvtidy/upstream` |
| `make build` | Build the static site into `site/out/` |
| `make test` | Run pytest, then vitest |
| `make helper` | Run the desktop helper (Session 6) |
